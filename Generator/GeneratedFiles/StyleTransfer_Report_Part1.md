# Optoelectronic Hybrid Neural Network for Image Style Transfer - Part 1: Overview & Research

## 1. Introduction

This report documents the implementation of an **optoelectronic hybrid neural network** for **image style transfer**. The system jointly optimizes a lightweight front neural network (which takes content images and outputs RGB amplitude arrays incident on the metasurface) and the metasurface phase array, producing a style-transferred image on the focal plane.

### Key Specifications:
- **Task**: Image Style Transfer (Generator)
- **Incident RGB Frequencies**: 480 THz (Blue), 560 THz (Green), 640 THz (Red)
- **Content Image**: `cont.png`
- **Style Image**: `style.png`
- **Focal Length**: 50 micrometers
- **Metasurface Parameters**: 
  - Nanopillar material: TiO2
  - Substrate material: SiO2
  - Period: 160 nm x 160 nm
  - N = 1024 (full grid)
  - Meta_N = 512 (active region)
  - zip = 16 (downsampling factor from encoder)

## 2. Academic Research Summary

### 2.1 Optoelectronic Hybrid Neural Networks

Optoelectronic hybrid neural networks combine **electronic neural networks** (for flexible computation) with **optical/photonic computing** (for high-speed, low-energy parallel processing). In this architecture:

- **Electronic Frontend (Encoder)**: A lightweight CNN processes the content image, producing amplitude modulation patterns for the metasurface.
- **Optical Backend (Metasurface + Free Space Propagation)**: The metasurface imposes phase modulation on the incident light, and Angular Spectrum Method (ASM) simulates propagation to the focal plane.

### 2.2 Image Style Transfer

Neural style transfer, pioneered by Gatys et al. (2016), uses convolutional neural networks (typically VGG-19) to separate and recombine content and style representations. The **content** is captured by high-level feature activations, while **style** is captured by correlations (Gram matrices) between feature maps.

### 2.3 Angular Spectrum Method (ASM)

ASM is a rigorous diffraction model that propagates optical wavefronts by:
1. Computing the angular spectrum via 2D Fourier transform
2. Applying the propagation transfer function in frequency domain
3. Inverse-transforming back to spatial domain

The propagation transfer function is:
```
H(fx, fy) = exp(j * 2π * z/λ * sqrt(1 - (λfx)^2 - (λfy)^2))
```

### 2.4 Metasurface Phase Modulation

A metasurface is an ultra-thin surface engineered with subwavelength nanostructures (nanopillars) that can control the phase, amplitude, and polarization of incident light. Here, TiO2 nanopillars on SiO2 substrate provide phase modulation via height adjustment. The phase relationship across frequencies is approximately linear:
```
Phase(f) = a(f) * Phase(480 THz) + b(f)
```

## 3. System Architecture

```
Content Image (cont.png)
         |
         v
[Front Neural Network (EncoderNet)]
   - Lightweight CNN: 512x512x3 -> 32x32x3
   - No BatchNorm layers
   - ~1.4M parameters
         |
         v (RGB Amplitude Arrays)
         |
[Kronecker Product Upsampling] (zip=16)
   - Expands 32x32 -> 512x512
         |
         v
[Padding] (from 512 -> 1024)
         |
         v
[Metasurface Phase Array] (1024x1024)
   - Phase modulation: exp(j * phase(x,y))
   - Frequency-dependent phase via linear mapping
         |
         v
[Angular Spectrum Propagation] (z=50um)
   - Separate propagation for each RGB frequency
         |
         v
[Output on Focal Plane] (1024x1024 per channel)
   - Cropped to 512x512 central region
         |
         v
[Compare with Style-Transferred Target]
   - Target generated by VGG-19 based style transfer
   - Loss: MSELoss between output and target
```

## 4. Meta-Atom Simulation Results

The simulation tool established linear phase relationships between different frequencies, referenced to 480 THz:

| Frequency (THz) | Phase Relationship (relative to Phase@480THz) |
|-----------------|-----------------------------------------------|
| 480             | Phase480 (reference)                          |
| 520             | 1.1002*Phase480 - 1.1411                     |
| 560             | 1.2022*Phase480 - 2.2877                     |
| 600             | 1.3120*Phase480 - 3.4718                     |
| **640**         | **1.4321*Phase480 - 4.7134**                 |
| 680             | 1.5529*Phase480 - 6.0218                     |
| 720             | 1.6911*Phase480 - 7.3980                     |

The **key frequencies used** (480, 560, and 640 THz) map RGB colors:
- **640 THz**: Red (wavelength ~469 nm) - through the red phase mapping
- **560 THz**: Green (wavelength ~536 nm) 
- **480 THz**: Blue (wavelength ~625 nm)

The relationship from nanopillar height to phase for each frequency:
```
Height_480 = (Phase480 - 6.6309) / -0.01349
Height_520 = (Phase520 - 6.1544) / -0.01484
Height_560 = (Phase560 - 5.6839) / -0.01622
Height_600 = (Phase600 - 5.2279) / -0.01770
Height_640 = (Phase640 - 4.7823) / -0.01932
```
