# Optoelectronic Hybrid Neural Network for Image Style Transfer - Part 1: Overview & Research (REVISED)

## 1. Introduction

This report documents the implementation of an **optoelectronic hybrid neural network** for **image style transfer**. The system jointly optimizes a lightweight front neural network (which takes content images and outputs RGB amplitude arrays incident on the metasurface) and the metasurface phase array, producing a style-transferred image on the focal plane.

### Key Specifications:
- **Task**: Image Style Transfer (Generator)
- **Incident RGB Frequencies**: 480 THz (Red), 560 THz (Green), 640 THz (Blue)
- **Content Image**: `cont.png`
- **Style Image**: `style.png`
- **Focal Length**: 50 micrometers
- **Metasurface Parameters**: 
  - Nanopillar material: TiO2
  - Substrate material: SiO2
  - Period: 160 nm x 160 nm
  - N = 1024 (full grid for propagation)
  - Meta_N = 512 (active image region)
  - zip = 16 (downsampling factor from encoder)

## 2. Academic Research Summary

### 2.1 Optoelectronic Hybrid Neural Networks

Optoelectronic hybrid neural networks combine **electronic neural networks** (for flexible computation) with **optical/photonic computing** (for high-speed, low-energy parallel processing). In this architecture:

- **Electronic Frontend (Encoder)**: A lightweight CNN (~398K parameters) processes the content image, producing amplitude modulation patterns for the metasurface.
- **Optical Backend (Metasurface + Free Space Propagation)**: The metasurface imposes phase modulation on the incident light, and Angular Spectrum Method (ASM) simulates propagation to the focal plane.

### 2.2 Image Style Transfer

Neural style transfer, pioneered by Gatys et al. (2016), uses convolutional neural networks (typically VGG-19) to separate and recombine content and style representations. The **content** is captured by high-level feature activations (conv_4 layer), while **style** is captured by correlations (Gram matrices) between feature maps across multiple layers (conv_1 through conv_5).

### 2.3 Angular Spectrum Method (ASM)

ASM is a rigorous diffraction model that propagates optical wavefronts by:
1. Computing the angular spectrum via 2D Fourier transform
2. Applying the propagation transfer function in frequency domain
3. Inverse-transforming back to spatial domain

The propagation transfer function is:
```
H(fx, fy) = exp(j * 2π * z/λ * sqrt(1 - (λfx)^2 - (λfy)^2))
```

### 2.4 Metasurface Phase Modulation

A metasurface is an ultra-thin surface engineered with subwavelength nanostructures (nanopillars) that control the phase, amplitude, and polarization of incident light. Here, TiO2 nanopillars on SiO2 substrate provide phase modulation via height adjustment. The phase relationship across frequencies is approximately linear:
```
Phase(f) = a(f) * Phase(480 THz) + b(f)
```

This enables a **single metasurface phase array** to simultaneously control all three RGB wavelengths through dispersion engineering.

## 3. System Architecture

```
Content Image (cont.png)
         |
         v
[Front Neural Network (EncoderNet)]
   - Lightweight CNN: 512x512x3 -> 32x32x3
   - No BatchNorm layers
   - ~398K parameters (4 downsampling blocks + output conv)
         |
         v (RGB Amplitude Arrays)
         |
[Kronecker Product Upsampling] (zip=16)
   - Expands 32x32 -> 512x512 via torch.kron
         |
         v
[Padding] (from 512 -> 1024)
   - Top/bottom: 256 zeros each; Left/right: 256 zeros each
   - Final size: 1024x1024 for diffraction calculation
         |
         v
[Metasurface Phase Array] (1024x1024)
   - Phase modulation: exp(j * phase(x,y))
   - Frequency-dependent phase via linear dispersion mapping
         |
         v
[Angular Spectrum Propagation] (z=50um)
   - Separate propagation for each RGB frequency
   - λ_Red = 625 nm, λ_Green = 536 nm, λ_Blue = 469 nm
         |
         v
[Output on Focal Plane] (1024x1024 per channel)
   - Cropped to 512x512 central region
         |
         v
[Compare with Style-Transferred Target]
   - Target generated by VGG-19 based neural style transfer
   - Loss: MSELoss between optically propagated output and target
   - Joint optimization updates both encoder and phase array
```

## 4. Meta-Atom Simulation Results

The simulation tool established linear phase relationships between different frequencies, referenced to 480 THz.

### Phase Dispersion Relationships (func_*.txt — used in DataFlow.py):
These define how the single learnable phase parameter maps to effective phase at each frequency:

| Frequency (THz) | Color | Phase Relationship (relative to Phase@480THz) |
|-----------------|-------|-----------------------------------------------|
| 480             | Red   | Phase480 (reference)                          |
| 560             | Green | 1.2022*Phase480 - 2.2877                     |
| 640             | Blue  | 1.4321*Phase480 - 4.7134                     |

### Height-to-Phase Relationships (freq_*.txt — from CST simulation):
The CST simulation established that nanopillar height maps to phase at each frequency. Given a desired phase at frequency f, the required height is:

```
Height_480 = (Phase_480 - 6.6309) / -0.01349   (for 480 THz, Red)
Height_560 = (Phase_560 - 5.6839) / -0.01622   (for 560 THz, Green)  
Height_640 = (Phase_640 - 4.7823) / -0.01932   (for 640 THz, Blue)
```

*Note: The `freq_*.txt` files describe absolute height-to-phase calibration from CST, while the `func_*.txt` files describe relative dispersion relationships used during optimization. Only the `func_*.txt` files are used in the training pipeline.*

### Key Insight: Dispersion Compensation
The linear mapping in `func_*.txt` ensures that the **same physical nanostructure** (with a single height profile encoding Phase480) produces the correct phase modulation at all three wavelengths simultaneously. This is essential for multi-wavelength metasurface design.
